# Portfolio Website

A personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, resume, and contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- About section
- Skills section
- Projects showcase
- Resume button
- Contact section
- Responsive design

## Key Learnings

- Built a responsive portfolio website.
- Improved HTML and CSS structuring.
- Used JavaScript for interactive functionality.
- Enhanced UI with a clean and organized design.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
