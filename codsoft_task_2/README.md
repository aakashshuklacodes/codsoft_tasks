# AUREX - Luxury Watch Landing Page

A modern landing page for a luxury watch brand built using HTML5 and CSS3.

## Features

- Hero section
- Product details
- Features list
- Pricing section
- Specifications table
- Learn More page
- Responsive viewport

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.

- `index.html`
- `learnmore.html`
